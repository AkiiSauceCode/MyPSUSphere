# MyPSUSphere

## Project Description

PSUSphere is a Django-based student organization management system designed to organize and manage information about colleges, academic programs, students, student organizations, and organization memberships. The system provides an organized way to manage student and organization-related data through a web-based platform.

## Features

* **College Management** – Add, view, search, and filter college information.
* **Program Management** – Manage academic programs and their associated colleges.
* **Student Management** – Store and manage student information, including student ID, name, and academic program.
* **Organization Management** – Manage student organizations, their descriptions, and associated colleges.
* **Organization Membership** – Record students who are members of student organizations.
* **Search and Filtering** – Search and filter records through the Django Admin interface.
* **Date Tracking** – Automatically record when records are created and updated.
